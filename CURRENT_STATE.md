# Current state

Verified on 2026-10-21 (America/Los_Angeles).

- Version 0.2: local book-library homepage, paired EPUB/PDF/Markdown/TXT import by file chooser or drag/drop, plus the existing legacy page-aligned datasets. Python + SQLite + `pypdf` + buildless HTML/CSS/JS. Windows launcher prefers the repository `.venv` when present.
- Query copied Chinese text, ignore punctuation/spacing, offer labeled lexical near matches, filter by book/chapter, and display source print/PDF page numbers.
- Reading-first workspace: one compact toolbar with book selection and a single search field, full-height side-by-side text panes, independent scrolling, chapter selection, and collapsed search results/settings. Candidate navigation and manual original browsing remain available; the library/import/settings interfaces are preserved.
- Imports paired text with explicit page markers. Includes an adapter for two existing workspace book datasets. Each book is validated before one transaction; changed chapter files/configurations invalidate confirmations.
- Human review saves contiguous source selections of up to four pages; exports can be restored only against matching versions.
- New file-library mode preserves uploaded files under ignored `data/books/<id>/`, extracts independent source/translation locations without requiring matching page numbers, and deduplicates identical file pairs. PDF scans without text require prior OCR. EPUB chapters and PDF document pages retain their own location labels.
- Cloudflare BGE-M3 integration: local settings/test-connection UI, Windows DPAPI credential storage (session-only on other OSes), resumable batch indexing, local cross-language vector candidate lookup, optional semantic query and candidate confirmation. Cloud calls require user-entered credentials; indexing and semantic search disclose the transmitted texts.
- Local library: four books. The user subsequently authorized model indexing of both complete PDF-original/EPUB-translation pairs. Both jobs are ready: 651/651 and 1717/1717 vectors, covering 1546 Chinese and 822 original text units. Book text was sent to the configured Cloudflare service for this indexing; files and vectors remain local. Two legacy selections retain their 15 chapters, 521 Chinese paragraphs, 217 original pages and nine reviewed mappings. No model candidate was automatically confirmed. All actual book data, paths, and mapping exports are ignored and absent from the public repository. A fresh clone starts empty.
- All-books text search covers both import formats, prioritizing exact matches over approximate results. Switching books updates the visible title and model availability; no-result text identifies the actual search scope. The original reader has an independent section/PDF-page-window selector so unindexed books can be browsed throughout without claiming alignment.
- Search defaults to automatic mode for an indexed book: an exact translated phrase/word uses stored vectors locally; an unmatched description sends the query to Cloudflare and ranks translated passages, then locates original candidates using the stored vectors. Semantic descriptions prefer prose units of at least 60 normalized characters when available, avoiding title/glossary-label results. Chapter opening likewise prefers substantive text; exact lookup still includes short units.
- Validation: 25 automated tests pass, plus browser JavaScript checks. Live indexing, exact term retrieval, a description query, chapter controls and desktop/narrow two-pane geometry were exercised. Inspected examples from both actual books located corresponding original material; these spot checks are not an accuracy benchmark. Credentials remain protected with Windows DPAPI and excluded from Git. Details: [reader and indexing update](docs/history/2026-10-21-reader-semantic-update.md).

Limitations: legacy books remain page-based unless manually reviewed and are not automatically vector indexed. Model matches are candidates, not verified sentence/word alignments; a translated paragraph can span several original units/pages. Short standalone headings can retrieve unrelated material, so chapter navigation starts at prose where available. No automatic OCR, DRM removal, original PDF page-image reader, or exact bilingual word selection. Mixed scanned/text PDFs only index extractable text; original layout/order can differ after extraction. Real retrieval has passed a few inspected examples, but broader quality and failure rates have not been measured.

GitHub holds source code, not a backup of the local library. Independent off-host backup for books/configuration has not been configured by this tool. See [local operations](docs/runbooks/local-library.md) and [roadmap](ROADMAP.md).
