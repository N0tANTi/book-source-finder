# Roadmap

- **P1 · Alignment quality beyond the local sequence window.** On-demand clause windows, monotonic range selection, page crossings, uncertainty labels and exact-range confirmations are implemented. Next evaluate omissions, reordered material, OCR damage, long passages and repeated ideas on a reviewed sample. Accept when failure rates and range coverage are measured; preserve human confirmations and abstain on unsupported cases.
- **P1 · Broader model evaluation.** Both full pairs are now indexed with explicit user authorization; live phrase and description queries work in inspected examples. Next review a structured sample across chapters, including merged/split passages and short-title failures. Accept when measured candidate quality and location failures are recorded; never promote model guesses to verified alignment automatically.
- **P2 · Reading controls.** Add previous/next chapter navigation, font size, and location persistence. Accept when moving chapters preserves correct book context and both readers remain usable at narrow widths.
- **P2 · Retrieval improvements.** Coarse BGE-M3 retrieval now feeds sentence/clause windows with surrounding-paragraph sequence constraints and range highlighting. Next measure ambiguity, improve the local corridor and sentence splitting for damaged OCR, and support cases that exceed the current bounded window. Exact word-level bilingual selection remains open.
- **P2 · Original page images.** Show an original PDF page at the retained PDF page number while keeping the text reader available. Requires a local PDF integration. Accept when scanned pages, front matter and printed/PDF numbering differences are verified.
