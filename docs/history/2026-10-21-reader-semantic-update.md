A compact toolbar contains book selection and one search field; results, settings and manual source browsing are collapsed. Indexed books default to exact-first automatic semantic search. A copied phrase uses local stored vectors for original candidates; an unmatched description uses a Cloudflare query embedding and then local candidate ranking. Existing text-only and legacy page-review paths remain available.

Live description testing exposed glossary labels outranking reading passages. Semantic translation ranking now prefers units of at least 60 normalized characters when available. Exact lookup continues to include short units, preferring substantive matching context first. A chapter-heading-only vector also retrieved unrelated illustration text; chapter navigation now begins with its first substantive unit when available. A checked late chapter then retrieved its corresponding original chapter. These changes do not establish a general accuracy rate or exact sentence alignment.
