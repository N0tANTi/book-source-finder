# Original range alignment

The reported mismatch came from treating a semantically retrieved PDF chunk as a translated paragraph's boundaries. One original chunk contained several translated paragraphs, while another translated paragraph crossed a chunk/page boundary. The prior UI highlighted the whole candidate chunk.

The fix retains coarse retrieval and adds BGE-M3 sentence/clause windows with local sequence optimization across neighboring translated paragraphs. It stores raw character ranges, displays multi-unit/page highlights, and suppresses unreviewed highlighting when no reliable range is available. Fine vectors and ranges are cached locally; first-time refinement is disclosed and user-triggered. Text-only mode does not start those calls. Human confirmation/cancellation preserves exact ranges without promoting neighboring model candidates to reviewed status.

Validation: 32 automated tests pass, covering cross-page ranges, exclusion of unrelated context, sequence order, cache reuse/invalidation, Unicode offsets, range confirmation/cancellation, cross-book rejection, partial batch retention, failure cooldown, weak-match abstention and HTTP consent. Both browser scripts pass syntax checks. In the live reader, the reported three adjacent paragraphs now select distinct source ranges, including the first paragraph's continuation across two PDF pages. Two further paragraphs split within one English sentence and one Stanzas passage were inspected. No real-book model result was marked human-confirmed. Broad accuracy remains unmeasured.

The migration adds three derived/review tables to the existing local database. Source files, extracted text, the 2368 existing coarse vectors and legacy confirmations remain unchanged. Runtime data and diagnostic examples are ignored. Database size after local validation was about 85 MB, with about 270 GB free on the verified data volume. Remaining work is recorded in the [roadmap](../../ROADMAP.md); limits, recovery and rollback caveats are in [passage operations](../runbooks/passage-alignment.md).
